# Numerical correction and validation - 8 October 2026

HS, HE and SJ were implementation errors. They were not defensible choices of the same named estimator. REML additionally returned an unconverged iterate on some unbalanced real datasets; it now falls back to optimisation of the restricted profile likelihood, including the zero boundary and a search for competing minima.

## External reference checks

The eight-study fixture records six shared tau-squared results from AllMeta's stored metafor reference (DL, HE, HS, SJ, REML and PM; absolute tolerance 1e-6). The CLASP example independently checks tau, pooled log odds ratio and standard error against the metafor author's published four-decimal results (tolerance 5.1e-5).

AllMeta also required a REML boundary-mode guard: CD006536 previously returned zero despite a higher interior restricted likelihood. Both repaired engines now agree across six methods on all three real-review fixtures; maximum tau-squared difference is below 2e-9. AllMeta passed 77 focused numerical and data-contract tests.

REML regression inputs are real Pairwise70 review data for CD005566, CD006536 and CD016031. Their expected solutions were checked by separate SciPy profile-likelihood optimisation. This is not a fresh R cross-validation run. The historical R report is retained with a correction notice.

The test suite passed 62 tests, including the real-data loader, 21 estimator reference/edge-case tests and three dashboard-refresh tests. CI now fails when pytest fails. The refresh tests cover pipeline-to-dashboard field mapping, quoted delimiters, inline-script escaping and refusing inconsistent input counts.
